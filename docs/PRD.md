# PRD - 실시간 외국어 음성 -> 한국어 번역 웹/앱

- 문서 버전: v0.1
- 작성일: 2026-04-19
- 상태: Draft
- 대상: 제품 방향, 범위, 우선순위, 운영 원칙 정의

## 1. 제품 한 줄 정의

컴퓨터, 노트북, 브라우저 탭, 앱 등에서 재생되는 외국어 음성을 실시간으로 받아 한국어 자막으로 보여주고, 필요하면 기록까지 남겨주는 웹사이트 및 데스크톱 앱을 만든다.

## 2. 문제 정의

사용자는 해외 강의, 라이브 방송, 영상, 회의, 게임 음성 채팅, 앱 내 음성 콘텐츠를 듣는 동안 언어 장벽 때문에 내용을 즉시 이해하지 못한다. 기존 방법은 다음과 같은 한계가 있다.

- 자막이 아예 없거나 한국어를 지원하지 않는다.
- 브라우저 번역은 텍스트에만 강하고, 시스템 오디오는 직접 다루기 어렵다.
- 실시간 통역 앱은 마이크 입력 중심이라 "컴퓨터에서 나오는 소리"를 안정적으로 잡지 못하는 경우가 많다.
- 여러 툴을 조합하면 설정이 복잡하고 지연이 커진다.

## 3. 비전

"내 기기에서 들리는 외국어를, 가장 적은 설정으로, 거의 실시간에 가깝게 한국어로 이해하게 해주는 도구"를 제공한다.

## 4. 목표 사용자

### 핵심 사용자

- 해외 강의, 유튜브, 스트리밍을 보는 사용자
- 외국어 회의/웨비나를 듣는 직장인
- 영어/일본어/중국어 게임 음성이나 커뮤니티 방송을 듣는 사용자
- 통역이 아니라 "빠른 이해용 한국어 자막"이 필요한 일반 사용자

### 초기 타깃

- Windows 사용자
- Chrome/Edge 기반 브라우저 사용자
- 데스크톱 환경에서 영상/오디오 콘텐츠를 많이 소비하는 사용자

## 5. 목표와 비목표

### 목표

- 컴퓨터에서 재생되는 외국어 음성을 실시간에 가깝게 한국어로 보여준다.
- 초기 진입 장벽이 낮아야 한다.
- 웹에서도 가능한 범위를 제공하되, 안정적인 시스템 오디오 캡처는 데스크톱 앱으로 보완한다.
- 세션 로그와 번역 결과를 저장하고 다시 볼 수 있어야 한다.
- Codex와 Claude Code를 병행해도 작업이 끊기지 않도록 문서 중심 운영 체계를 갖춘다.

### 비목표

- 초기 버전에서 전문 동시통역 수준의 완벽한 번역 품질 보장
- 초기 버전에서 모바일 OS 전체 시스템 오디오 캡처 지원
- 초기 버전에서 모든 언어 쌍 번역 지원
- 초기 버전에서 화자 분리, 감정 분석, 완전 자동 요약까지 모두 포함

## 6. 제품 범위

### MVP 범위

- 시스템 오디오 또는 브라우저 탭 오디오 입력 받기
- 언어 자동 감지
- 실시간 음성 인식
- 한국어 번역 자막 표시
- 세션별 원문/번역 기록 저장
- 세션 종료 후 텍스트 내보내기
- 오류 메시지 및 권한 안내
- 작업 기록과 핸드오프 문서화

### Post-MVP 범위

- 화자 분리
- 사용자 용어집
- 한국어 음성 출력
- 모바일 보조 앱
- 회의 플랫폼별 특화 연동
- 개인화 번역 스타일

## 7. 핵심 사용 시나리오

### 시나리오 A - 해외 강의 시청

사용자는 웹사이트 또는 데스크톱 앱에서 "세션 시작"을 누르고, 현재 재생 중인 탭/시스템 오디오를 선택한다. 몇 초 안에 언어가 감지되고, 한국어 자막이 하단에 쌓인다.

### 시나리오 B - 외국어 회의 청취

사용자는 데스크톱 앱으로 회의 소리를 캡처하고, 실시간 한국어 번역 자막을 본다. 회의 종료 후 전체 기록을 복사하거나 저장한다.

### 시나리오 C - 스트리밍/영상 콘텐츠 이해

사용자는 게임 방송이나 라이브 스트리밍을 켠 상태에서 번역 자막을 별도 창으로 띄워 본다.

## 8. 사용자 스토리

- 사용자는 복잡한 오디오 설정 없이 바로 번역을 시작하고 싶다.
- 사용자는 어떤 입력이 잡히는지 명확히 알고 싶다.
- 사용자는 번역 지연이 너무 길지 않기를 원한다.
- 사용자는 중요한 문장을 놓쳤을 때 직전 기록을 다시 보고 싶다.
- 사용자는 세션이 끊겨도 작업 상태와 기록이 사라지지 않기를 원한다.
- 개발자는 Codex나 Claude Code 어느 쪽으로 이어도 맥락 손실 없이 개발을 재개하고 싶다.

## 9. 기능 요구사항

### 필수 기능

1. 오디오 입력 선택
2. 세션 시작/일시정지/종료
3. 실시간 자막 영역
4. 원문과 한국어 번역 동시 표시
5. 언어 자동 감지 및 수동 선택
6. 세션 기록 저장
7. 기록 복사/내보내기
8. 오류 및 권한 안내 UI
9. 작업 체크포인트 및 핸드오프 기록 체계

### 선택 기능

1. 자막 글자 크기 조절
2. 번역 품질/속도 모드 선택
3. 특정 앱/탭 프리셋
4. 최근 세션 다시 열기

## 10. 비기능 요구사항

- 응답성: 체감 지연은 가능한 2~4초 이내를 목표로 한다.
- 안정성: 장시간 세션에서도 메모리 누수와 연결 끊김이 낮아야 한다.
- 명확성: 사용자에게 현재 어떤 오디오가 캡처되는지 분명히 보여줘야 한다.
- 확장성: STT, 번역, 저장소 공급자를 교체할 수 있어야 한다.
- 관측성: 세션 실패 원인, 지연 시간, 비용을 추적할 수 있어야 한다.
- 복구성: AI 세션이 중단돼도 마지막 체크포인트 기준으로 바로 복구 가능해야 한다.

## 11. 성공 지표

### 제품 지표

- 세션 시작 성공률
- 5분 이상 세션 유지율
- 사용자당 평균 주간 세션 수
- 세션당 번역 자막 표시율

### 품질 지표

- 평균 종단 지연
- 번역 정확도에 대한 사용자 만족도
- 세션 중 오류 발생률
- 재시도 없이 세션 복구 가능한 비율

### 운영 지표

- 작업 핸드오프 후 재개 시간
- 토큰 소진 후 복구 실패 건수
- 작업 중복 발생률

## 12. 제약 및 리스크

### 제품 리스크

- 순수 웹만으로는 모든 환경에서 시스템 오디오 캡처가 어렵다.
- OS와 브라우저에 따라 권한/지원 범위가 다르다.
- 번역 품질과 지연 시간 사이에 트레이드오프가 있다.
- 장시간 음성 스트리밍은 비용 부담이 커질 수 있다.
- 회의/콘텐츠 녹음 관련 법적 고지와 사용자 책임 안내가 필요하다.

### 운영 리스크

- Codex와 Claude Code가 같은 파일을 동시에 건드리면 충돌이 날 수 있다.
- 세션 종료 전에 요약이나 체크포인트를 남기지 않으면 문맥 손실이 커진다.
- 모델별 답변 스타일 차이로 아키텍처가 흔들릴 수 있다.

## 13. 운영 원칙 - Codex + Claude Code 협업

### 협업 기본 원칙

- 문서가 대화보다 우선한다.
- 한 번에 한 에이전트가 한 파일군의 최종 수정 책임을 가진다.
- 결정은 반드시 문서화한다.
- 세션 종료 전에는 반드시 체크포인트를 남긴다.

### 역할 분담 권장안

- Codex: 코드 구현, 패치 적용, 테스트 실행, 리팩터링, 파일 단위 수정
- Claude Code: 구조 검토, 긴 문서 정리, 대안 비교, 리스크 리뷰, 프롬프트 설계 보조

### 공통 규칙

- 기준 문서는 `docs/PRD.md`, `docs/TRD.md`다.
- 새로운 의사결정은 `docs/DECISIONS/`에 남긴다.
- 현재 작업 현황은 `.ops/task-log.md`에 갱신한다.
- 세션 종료 직전 다음 담당자가 바로 이어받을 수 있게 핸드오프를 남긴다.
- Claude와 Codex 간 문서형 협업은 `.ops/ai-bridge/` 프로토콜을 사용한다.

## 14. 토큰 소진/작업 중단 대비 요구사항

### 반드시 저장해야 하는 것

- 지금까지 바뀐 파일 목록
- 현재까지 확정된 결정
- 아직 안 끝난 작업
- 다음 세션이 바로 실행할 첫 단계
- 실행한 명령과 검증 결과

### 저장 방식

- 문서 변경은 저장 후 Git 추적 대상에 둔다.
- 중간 상태라도 이해 가능한 단위면 `WIP` 커밋으로 남긴다.
- 아직 커밋이 이르다면 `.ops/checkpoints/`에 체크포인트 문서를 남긴다.
- 이어받기용 프롬프트를 같이 저장한다.

## 15. 출시 단계 제안

### Phase 0 - 문서/골격

- PRD/TRD 정리
- 모노레포 구조 확정
- 체크포인트 체계 구축

### Phase 1 - Windows MVP

- 데스크톱 앱에서 시스템 오디오 캡처
- 실시간 STT + 한국어 번역
- 웹 UI 또는 데스크톱 내 자막 화면
- 세션 저장

### Phase 2 - 웹 개선

- 브라우저 탭 오디오 캡처
- 계정/세션 동기화
- 품질/속도 모드

### Phase 3 - 고도화

- macOS 지원
- 용어집
- 화자 분리
- 한국어 TTS

## 16. MVP 출시 기준

- Windows에서 시스템 오디오 입력이 가능하다.
- 최소 1개 이상의 외국어 입력에 대해 한국어 자막이 실시간으로 표시된다.
- 세션 기록이 저장되고 다시 볼 수 있다.
- 오류 상황에서 사용자가 무엇을 해야 하는지 알 수 있다.
- 작업 문서와 체크포인트 체계만으로 다른 AI가 즉시 개발을 이어갈 수 있다.
