# Claude 90% Handoff Prompt

아래 지시를 그대로 따르세요.

## 목표
- 토큰/쿼터 사용량이 90% 이상일 때, 기능 구현보다 **인수인계 완결성**을 최우선으로 전환한다.
- 다음 작업자가 5분 내 재시작 가능하도록 상태를 남긴다.

## 즉시 실행 순서
1. 현재 실행 중 작업을 안전한 경계(테스트 1회 완료, 파일 저장 완료)에서 멈춘다.
2. 아래 4개를 반드시 업데이트한다.
   - `.ops/checkpoints/YYYY-MM-DD-<step>.md`
   - `.ops/handoff-YYYY-MM-DD-claude-to-codex-<step>.md`
   - `.ops/ai-bridge/shared-context.md`
   - (있으면) `.ops/task-log.md`
3. **재실행 명령어**를 복붙 가능한 형태로 기록한다.
4. 남은 리스크/미완료 작업을 우선순위로 3개 이내 작성한다.
5. 변경 파일을 커밋하고 커밋 해시를 handoff 문서에 남긴다.

## 문서 필수 항목
- 현재 목표/범위
- 완료한 것 (파일 경로 포함)
- 실패/이슈 (오류 로그 핵심 3줄)
- 다음 1~3단계 액션
- 실행 커맨드
- 최신 리포트/아티팩트 경로

## 출력 형식 규칙
- 한국어로 작성
- 과장 금지, 사실 기반
- “무엇을 했는지 / 무엇이 남았는지 / 어떻게 재시작하는지”를 짧고 명확하게
